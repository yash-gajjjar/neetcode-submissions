# Data Structures & Algorithms

Python solutions and study notes for data structures and algorithm problems.

## Repository layout

- `Data Structures & Algorithms/` — problem solutions.
- `abdulbari_BigO.md` — notes on time and space complexity.

## How I use this repository

I organize practice around problem-solving patterns and focus on understanding the invariant behind a solution, not just memorizing code.

For each problem, the useful review points are:
- Core idea and why it works.
- Time and space complexity.
- Edge cases.
- Alternative approaches where they offer a meaningful trade-off.

The repository is a work in progress; it does not claim complete coverage of a specific interview question set.
